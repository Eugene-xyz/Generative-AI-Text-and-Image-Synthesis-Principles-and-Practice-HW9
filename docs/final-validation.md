## 驗證界線

沒有替使用者建立 Repository、上傳或啟用 GitHub Pages，沒有可宣稱已驗證的公開網址。尚未實際測試 file:// 雙擊、真實手機、所有平台的完整音訊播放或所有外部來源當日可用性。相對檔案與內嵌腳本已檢查；公開後仍需依 [發布步驟](github-pages.md) 驗證實際網址。

正式交付不表示資料全無缺漏：LP 曲序、部分合作影音日期／語言與再次收錄的錄音關係等，繼續依 [待查表](../wiki/questions.md) 明示。沒有為交付把 partial 改成 checked。
